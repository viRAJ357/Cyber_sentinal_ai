# Cyber Sentinel AI

A beginner-friendly defensive cybersecurity project built with Python for Termux.

## Features
- Basic Termux security audit
- SSH permission checks
- Sensitive filename privacy warnings
- SHA-256 file integrity monitoring
- JSON scan reports

## Usage

Run the security audit:

    python sentinel.py

Create a file integrity baseline:

    python integrity.py baseline ~/cyber-sentinel-ai

Check for file changes:

    python integrity.py check ~/cyber-sentinel-ai

## Disclaimer
This is an educational prototype, not a complete antivirus or malware detector.
