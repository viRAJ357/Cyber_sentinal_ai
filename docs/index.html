CAPABILITIES

Built for investigation

01
Baseline comparison

SHA-256 digests identify content changes relative to a trusted inventory.

02
Signed baseline validation

HMAC-SHA256 can detect baseline tampering when the secret key is protected.

03
Explainable triage

Findings include file metadata signals and reasons for human review.

04
JSON reports

Reports support debugging, demos and audit workflows.

ARCHITECTURE

A simple, auditable pipeline

Target folder → SHA-256 scan → Baseline comparison
Change events → Anomaly triage → JSON report
Monitor / Local API → Console and dashboard
Anomaly scores prioritize review; they do not prove a file is malicious. The optional ML path uses Isolation Forest only when the dependency is installed and enough reference files and events are available.
LOCAL WORKFLOW

Run in Termux

Use a trusted project folder and keep the HMAC key outside Git. If a baseline already exists, do not overwrite it just to make a scan pass.

cd ~/cyber-sentinel-ai
python integrity.py check ~/cyber-sentinel-ai
python -m unittest discover -s tests -v

API routes: GET /api/status · POST /api/scan. The development API must remain on localhost; do not expose it directly to the public internet.
