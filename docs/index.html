Run locally in Termux

In your project folder, create a baseline from a trusted state, then run a check:

cd ~/cyber-sentinel-ai
python integrity.py baseline ~/cyber-sentinel-ai
python integrity.py check ~/cyber-sentinel-ai

Continuous monitoring: python monitor.py ~/cyber-sentinel-ai --interval 10

Exit 0: clean · Exit 1: changes detected · Exit 2: operational error/incomplete scan.

Educational prototype, not an antivirus. A file change is not proof of an attack. Never expose the unauthenticated development API to the public internet.
